# Project Atlas

Project Atlas is an AI-native personal operating system designed to help me identify, begin, track and complete my highest-value work.

It is also an applied AI engineering lab for learning:

- AI-native product design
- Agentic workflows
- Context engineering
- Tool use and APIs
- Automation
- Human-in-the-loop systems
- Evaluation and iteration

## Current phase

Discovery and initial build.

## Initial platform roles

- Notion: structured operational system
- ChatGPT: product lead, tutor and reasoning partner
- GitHub: technical documentation and version control
- Google Calendar: authoritative calendar
- Gmail: authoritative email
- Automation and coding tools: to be introduced incrementally

## Core principle

Build the smallest useful system, use it in real life, observe what happens, and improve it iteratively.
